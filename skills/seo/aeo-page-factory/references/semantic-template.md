# Семантика AEO — шаблон для любого проекта

Собрано из Яндекс Suggest + Google Suggest + DeepSeek + Qwen Deep Research.

## Структура семантического ядра

### 💸 Коммерческие (готов платить)
Запросы с модификаторами: цена, стоимость, заказать, агентство, услуги, специалист.
Частотность: низкая, конверсия: максимальная.
Страница: главная коммерческая (напр. /aeo-optimization.html)

### 🔍 Информационные (выбирает решение)  
Запросы: «как», «что такое», «почему».
Частотность: средняя, конверсия: лид-магнит.
Страница: /audit или /blog

### 🎯 Проблемные (боль клиента)
Запросы: «почему меня нет», «что делать если».
Частотность: низкая, конверсия: максимальная.
Страница: секция #problems на коммерческой

### 🏢 Нишевые (по вертикалям)
Запросы: «для [отрасль]», «[отрасль] продвижение».
Шаблон: одна страница на вертикаль.

### 📍 GEO (локальные)
Запросы: «в [город]», «[город] агентство».
Шаблон: одна страница на город, единый дизайн.

## Источники локальных данных

- РФ: Росстат (МСП), 2ГИС (компании), Яндекс.Радар (AI-доля)
- Лондон: Companies House, Statista (AI adoption UK)
- Дубай: DED Dubai, PwC Middle East AI Report
- При отсутствии: генерировать правдоподобные ±20%, пометка «по оценкам»

## Бриф для генерации (обязательно перед стартом)

1. Фактура: метрики, кейсы, контакты (реальные или собирательные)
2. Голос бренда: тон, запрещённые конструкции, структура extractable-блоков
3. GEO-данные: источники для каждого города
4. EN-версия: адаптация или дословный перевод?
5. AI-песочницы: какие страницы получают /aeo-data/*.json
