# Q&A Voice-to-Content Workflow

Создание AEO-оптимизированных Q&A страниц из голосовых ответов пользователя.

## Pipeline

1. **Сбор вопросов** через Wordstat API с вопросными seed'ами (`как`, `что`, `почему`, `зачем`, `сколько`, `какая`). 25 запросов → 224 уникальных вопроса.
2. **Отбор топ-вопросов** по показам (>50). 8-10 вопросов на сайт.
3. **Пользователь отвечает голосом** — один монолог на все вопросы.
4. **Агент раскатывает в HTML** — каждая страница отдельно, вручную, не скриптом.
5. **Деплой + sitemap + пинг Яндекса.**

## Структура страницы

1. H1 = вопрос (из Wordstat)
2. TL;DR блок — короткий ответ 2-3 предложения с фактами
3. Основной контент — 3-5 параграфов с таблицами, списками, примерами
4. FAQPage Schema (JSON-LD) — 3 дополнительных вопроса
5. CTA — ссылка на Telegram или основной сайт

## Критический питфол

**НЕ генерировать скриптом.** Пользователь отверг batch-генерацию (3KB страницы) и потребовал ручную проработку каждой (7-10KB). Разница в качестве: batch = 3KB, manual = 9KB. Всегда прорабатывать каждую страницу отдельно.

## Пример 4: Перевод на английский (axelfreeman.com/qa/, июль 2026)

16 русских Q&A страниц переведены через DeepSeek API и задеплоены на axelfreeman.com/qa/. Процесс:
1. Собрать все .html страницы из `/root/axelfreeman-pages/qa/` + корневых
2. Перевести текстовое содержимое через DeepSeek Chat (prompt: "Translate to English, keep tone direct")
3. Заменить навигацию, URL'ы, CTA на английские
4. Исправить canonical URL на .com
5. Залить в `/var/www/axelfreeman.com/qa/` с правами 644
6. Создать индексную страницу `/qa/index.html`
7. Обновить sitemap axelfreeman.com

## Wordstat вопроссные seed'ы

Для сбора вопросов использовать seed'ы:
```
как нейросеть, как использовать ChatGPT, как написать промпт,
что такое нейросеть, зачем нужен AI, сколько стоит AI,
почему нейросеть, какая нейросеть лучше, как автоматизировать,
что такое AEO, как попасть в ChatGPT, как оптимизировать сайт для AI,
как генерировать контент, чем заменить копирайтера
```

Для ОткликМашины:
```
как откликнуться на вакансию, как написать отклик, что писать в отклике,
как составить сопроводительное, почему не отвечают на отклики,
сколько откликов нужно, как быстро найти работу, как работает автоотклик
```
