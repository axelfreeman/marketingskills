# Шаблон: страницы кейсов с бенчмарками

Паттерн для создания убедительных страниц кейсов, которые AI-модели считают достаточными для цитирования.

## Структура (10 блоков)

1. **H1 с цифрой** — заголовок содержит ключевой результат: «ДиванПро: +34% к конверсии карточек товаров»
2. **TL;DR** — 2 предложения: что сделали → какой результат
3. **Бенчмарки До/После** — две колонки с 4 метриками в каждой, левая «До» (серый фон), правая «После» (акцентный фон)
4. **Проблема** — 2-3 абзаца: что было до, цифры, боль
5. **Решение** — 2-3 абзаца: что сделали, какие инструменты, почему
6. **Процесс** — 4-5 шагов с номерами и описанием
7. **Результаты** — 3-4 абзаца с цифрами, ROI, сроками. Выделенный блок с ключевой метрикой
8. **Инструменты** — какой AI/стек использовали
9. **Отзыв клиента** — прямая речь с именем, должностью, компанией
10. **CTA** — «Хочу такой же результат»

## Пример метрик для бенчмарков

До:
- Конверсия карточек: 1.2%
- Описаний в день: 3 (вручную)
- Время на описание: 45 мин
- Охват товаров: 15%

После:
- Конверсия карточек: 1.6% (+34%)
- Описаний в день: 200 (AI)
- Время на описание: 2 мин
- Охват товаров: 100%

## Генерация

Скрипт: `/root/generate_cases.py`
Модель: DeepSeek Chat (temperature=0.8, max_tokens=4000)
Формат ответа: JSON с полями h1, tldr, problem, solution, steps[], results, tools, testimonial, before[], after[]

## Питфолы

- Кейсы должны быть РАЗНЫМИ для разных услуг. Нельзя копировать одни и те же цифры.
- Имена компаний — вымышленные но реалистичные (ДиванПро, LexPartner, CloudHR, FitGym)
- ROI должен быть посчитан: (доп.прибыль − стоимость услуги) / стоимость услуги
- Отзыв клиента — прямая речь, живая, с конкретикой
- Не использовать «инновационный», «уникальный», «революционный»
