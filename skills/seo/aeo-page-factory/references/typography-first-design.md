# Типографика первична: дизайн-принципы для Axel Freeman

Принято 15 июля 2026 после изучения дизайна Вастрика (vas3k.blog).

## Главный принцип

**Цвет — специя, не структура. Страница должна работать в чёрно-белом.**

Цвет добавляет эмоцию, но не несёт информацию. Иерархия — через типографику: размер, вес, воздух.

## Правила

### Цвет
- Один акцентный цвет: `#2563eb` (синий). Только для ссылок и CTA-кнопки.
- Не использовать акцентный цвет на: заголовках, цифрах в статах, номерах шагов, названиях секций, заголовках таблиц.
- Зелёный (`#10b981`) — не использовать. Создаёт конфликт с синим, отвлекает от текста.
- Единственное исключение: кнопка Telegram может быть `#2AABEE` (фирменный цвет Telegram).

### Типографика
- **Заголовки:** Merriweather, weight 300-400. Центрированы. 70-150px воздуха сверху.
- **Тело:** Merriweather, weight 300. 105-125% размера. Межстрочный 1.67.
- **UI-элементы (меню, кнопки, лейблы):** Ubuntu, weight 400-500.
- **Никакого bold (700)** — только regular/medium weight.

### Карточки
- Белые, border-radius 30px, мягкая тень `10px 15px 40px rgba(83,91,110,0.10)`.
- Заголовок карточки — чёрный Merriweather, не цветной.
- Фон страницы — `#f5f6f8` (тёплый серый). Не чисто белый, не тёмный.

### Воздух
- Hero: 120-140px padding-top.
- Между секциями: 60-100px.
- Заголовки секций: 70-100px padding-top.
- Текст: max-width 800-900px, с отступом слева 35px (как у Вастрика).

## Антипаттерны

❌ Размазывать акцентный цвет по всей странице («доминирование одного цвета»)
❌ Использовать зелёный + синий одновременно (конфликт двух насыщенных цветов)
❌ Жирные заголовки (font-weight: 700) — убивают воздух
❌ Плотный контент без отступов — глазу не за что зацепиться
❌ Тёмный фон для контентных страниц — утомляет при чтении

## Примеры «цвет мешает глазу» (как НЕ надо)

- Синие цифры в статах
- Синие названия кейсов
- Синие номера шагов
- Фиолетовый/синий заголовок hero
- Зелёные блоки «→ Решение»

## Как проверять

После смены дизайна: открыть страницу, прищуриться. Если глаз цепляется за цветные пятна, а не за текст — цветов слишком много.
